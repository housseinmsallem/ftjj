# CMS plateforme FTJJ

Le CMS expose `/api/cms/homepage` et `/api/cms/platform-settings`. Les pages admin `/admin/cms`, `/admin/homepage-editor` et `/admin/platform-settings` permettent de modifier le hero, les CTA, les sections actives, le nom officiel, les couleurs, les logos, les sponsors et le footer. Les modifications sensibles sont journalisees dans `AuditLog`.
