# Recette fonctionnelle FTJJ

## Public
- Accueil avec slider publié depuis le constructeur.
- Pages compétitions, rankings, live scoring, clubs et athlètes.
- Affichage responsive mobile/tablette/desktop.

## Fédération
- Connexion admin.
- Validation clubs, licences, documents.
- Gestion compétitions, paiements, contenus publics.
- Export CSV.
- Notifications fédérales.
- Paramètres saison/prix/contact.
- Audit logs.

## Club
- Dashboard club.
- Consultation athlètes, licences, documents, paiements.

## Production
- Nginx + HTTPS + PM2.
- MongoDB Atlas recommandé.
- Sauvegarde quotidienne DB et uploads.
